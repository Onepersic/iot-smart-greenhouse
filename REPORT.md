# Отчёт по лабораторной работе: IoT Smart Greenhouse

## Цель и результат

Создан и опубликован учебный прототип панели умной теплицы. Интерфейс показывает телеметрию трёх зон, имитирует показания датчиков, поддерживает автоматический и ручной режимы, отображает предупреждения и журнал событий, строит графики и вычисляет индекс риска.

Опубликованный проект: [GitHub Pages](https://onepersic.github.io/iot-smart-greenhouse/). Исходный код: [репозиторий GitHub](https://github.com/Onepersic/iot-smart-greenhouse).

## Архитектура

- **HTML-страницы:** `index.html` задаёт вход в приложение; `dashboard.html`, `zones.html`, `sensors.html`, `control.html`, `alerts.html`, `analytics.html` и `settings.html` содержат разделы панели.
- **Общие стили:** `assets/css/style.css` задаёт адаптивную сетку, компоненты и светлую/тёмную темы.
- **Данные и состояние:** `assets/js/data.js` содержит начальные данные зон, датчиков, порогов и исполнительных устройств; `assets/js/storage.js` сохраняет и загружает состояние через `localStorage`.
- **Симуляция и автоматика:** `assets/js/simulator.js` обновляет учебную телеметрию; `assets/js/automation.js` управляет насосом, вентиляцией, светом, увлажнителем, обогревателем и форточкой.
- **Представление:** `assets/js/dashboard.js` отображает показатели и графики; `assets/js/alerts.js` формирует события и предупреждения; `assets/js/analytics.js` вычисляет риск и рекомендации.
- **Библиотека графиков:** Chart.js подключается со страницы через CDN.

Поток данных: симулятор обновляет состояние → автоматика применяет пороги и блокировки → состояние сохраняется → страницы обновляют показатели, графики и журнал.

## Проверки

| Сценарий | Результат |
|---|---|
| Страницы проекта открываются по отдельным URL; меню ведёт в нужные разделы | Пройдено на опубликованном сайте |
| Dashboard показывает шесть KPI, три зоны, состояние датчиков и открытые предупреждения | Пройдено |
| Страница зон отображает карточки и поиск/фильтр | Пройдено |
| Страница датчиков показывает показания, зоны, состояние связи и давность обновления; поиск ограничивает список | Пройдено |
| Страница управления содержит шесть исполнительных устройств и пороговые значения | Пройдено |
| Ручной режим разрешает переключатели, автоматический режим блокирует ручные переключения | Пройдено ранее при проверке сайта; текущий режим оставлен AUTO |
| Аналитика отображает оценку риска 0–100, разбор факторов, рекомендации и диаграмму | Пройдено |
| Скорость симуляции ограничена интервалами 3, 5 и 10 секунд | Реализовано; проверка списка настроек ожидает публикации последнего исправления |
| Журнал отображает предупреждения с категорией, зоной, датчиком, временем и статусом; предусмотрены фильтры | Метаданные проверены; найдены старые повторные записи, добавлена очистка дублей при загрузке, требуется проверка после публикации |
| Пороговый уровень воды блокирует насос; почвенный порог управляет поливом с гистерезисом | Реализовано в логике автоматики; отдельная постановка экстремальных значений в браузере не выполнялась |
| Изменения состояния сохраняются в `localStorage` | Подтверждено работой общего сохранения; полный тест перезагрузки для каждого параметра не выполнялся |
| JavaScript без синтаксических ошибок; файлы страниц и локальные ресурсы связаны | Проверено локально после последних изменений |
| Консоль браузера | На свежей загрузке опубликованной сборки ошибок не было; защита уведомления дополнительно исправлена локально |
| Переключение светлой/тёмной темы | Проверено на опубликованном сайте; после проверки возвращена светлая тема |
| Адаптивность при 1920, 1366, 768 и 390 px | CSS содержит адаптивные правила, но визуальный прогон на всех четырёх ширинах ещё не зафиксирован |

## Вывод

Реализованы основные функции лабораторной: многостраничная панель, симуляция IoT-телеметрии, ручное и автоматическое управление, защита насоса при критическом уровне воды, журнал предупреждений, аналитика, сохранение состояния и публикация через GitHub Pages. Для окончательного отчёта ещё нужны снимки интерфейса, визуальный прогон на мобильной ширине 390 px и браузерный сценарий безопасной блокировки насоса.
