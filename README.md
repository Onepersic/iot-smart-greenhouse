# IoT Smart Greenhouse

Учебный адаптивный прототип мониторинга и управления умной теплицей. Сайт использует демонстрационную телеметрию и не подключается к реальным устройствам.

## Запуск

Откройте `index.html` или запустите каталог через VS Code Live Server. Для графиков требуется доступ к CDN Chart.js.

## Страницы

- `dashboard.html` — KPI, зоны, оповещения и графики.
- `zones.html` — карточки зон, статус датчиков и оценка риска.
- `sensors.html` — значения, Online/Offline, время обновления и фильтры.
- `control.html` — режимы Manual/Auto, исполнительные устройства и пороги.
- `alerts.html` — журнал, фильтры и отметка обработки оповещений.
- `analytics.html` — риск, резкие изменения и рекомендации.
- `settings.html` — тема, скорость симуляции, оператор и пороги.

## Возможности

- Три зоны выращивания и шесть типов датчиков, включая уровень воды.
- Симуляция значений с настраиваемым интервалом 1–10 секунд.
- Ручной и автоматический режимы для насоса, вентилятора, фитоламп, увлажнителя, обогревателя и форточки.
- Безопасная блокировка насоса при критическом уровне воды; пороги полива используют гистерезис.
- Оповещения, журнал действий, фильтры, экспорт демонстрационных данных и сохранение состояния в `localStorage`.
- Четыре графика Chart.js, оценка риска и локальные рекомендации.
- Светлая и тёмная темы, адаптивная раскладка.

Пороговые значения демонстрационные и настраиваются оператором. Данные симулятора не являются показаниями реальных IoT-устройств.
