# IoT Smart Greenhouse

Учебная адаптивная панель для мониторинга и управления умной теплицей. Интерфейс использует демонстрационные данные, имитирует телеметрию датчиков и сохраняет состояние в `localStorage`.

## Запуск

Откройте `index.html` в браузере: он перенаправит на `dashboard.html`. Для графиков нужен доступ к CDN Chart.js.

## Страницы

- `dashboard.html` — общий обзор и графики.
- `zones.html` — показатели зон выращивания.
- `sensors.html` — список подключённых датчиков.
- `control.html` — ручной и автоматический режимы, пороговые значения.
- `alerts.html` — журнал событий и оповещений.
- `analytics.html` — индекс риска и рекомендации.
- `settings.html` — тема оформления и параметры профиля.

## Структура

- `assets/css/style.css` — стили и адаптивная тёмная тема.
- `assets/js/data.js` — начальные данные зон и датчиков.
- `assets/js/storage.js` — сохранение состояния в браузере.
- `assets/js/simulator.js` — имитация телеметрии.
- `assets/js/automation.js` — логика автоматического управления.
- `assets/js/dashboard.js` — отображение интерфейса и обработка действий.
- `assets/js/alerts.js` — оповещения и журнал событий.
- `assets/js/analytics.js` — индекс риска и рекомендации.

Данные симулятора не являются показаниями реальных IoT-устройств.
